> **Kurze Antwort:** Für den Anfrageprozess reichen fünf Quoten: Erreichung, Terminvereinbarung, Erscheinen, Annahme des Behandlungsplans und Behandlungsbeginn. Dazu kommt der Median der ersten Reaktionszeit. Jede Quote wird mit den eigenen letzten 90 Tagen verglichen, nicht mit Branchenwerten. Die Zahlen stehen auf einer einseitigen Wochenkarte, und jede Woche werden einige zufällig gewählte Gespräche mit einem 10-Punkte-Bogen ausgewertet. So sieht man nicht nur, dass sich eine Zahl verändert hat, sondern auch warum.

## Was ist eine Kennzahl für Patientenanfragen?

Eine Kennzahl für Patientenanfragen zeigt, welcher Anteil der Anfragen von einer Stufe zur nächsten gelangt, vom ersten Kontakt bis zum Behandlungsbeginn. Viele Praxen schauen nur auf zwei Zahlen: wie viele Anfragen über Werbung oder soziale Medien kamen und wie viele Behandlungen am Monatsende stattfanden. Alles dazwischen bleibt im Dunkeln. Läuft ein Monat schlecht, weiß niemand, ob das Problem bei der Werbung, am Telefon, im Behandlungsplan oder beim Nachfassen liegt, also wird meist am sichtbarsten Hebel gedreht: dem Werbebudget. Die Messung Stufe für Stufe zeigt, wo genau Anfragen verloren gehen. Dieser Teil liefert eine Wochenkarte, die eine Koordinatorin in einer halben Stunde pro Woche ausfüllt, und einen Gesprächsbogen, mit dem das Team die Gesprächsqualität bewertet. Ziel ist kein Bericht, sondern jede Woche eine Sache zu verbessern.

## Fünf Kernquoten

| Quote | Formel | Was sie zeigt |
|---|---|---|
| 1. Erreichungsquote | Anfragen mit begonnenem Gespräch / eingegangene Anfragen | Tempo und Kanal der ersten Antwort |
| 2. Terminquote | Vereinbarte Termine / Anfragen mit Gespräch | Qualität des ersten Gesprächs |
| 3. Erscheinensquote | Erschienene / vereinbarte Termine | Erinnerung und Vertrauen |
| 4. Planannahmequote | Angenommene / vorgestellte Behandlungspläne | Plan, Kosten und Nachfassen |
| 5. Beginnquote | Begonnene Behandlungen / angenommene Pläne | Anzahlung, Terminierung, letzte Sorgen |

Das Produkt der fünf Quoten ergibt die Gesamtumwandlung von der Anfrage bis zum Behandlungsbeginn. Sinkt sie, zeigt der Blick auf die gesunkene Einzelquote, wo man ansetzen sollte.

Wir nennen bewusst keinen allgemeinen „guten“ Wert. Praxen mit unterschiedlichen Behandlungen, Kanälen, Standorten und Preisniveaus über eine Zahl zu vergleichen, führt in die Irre. Der richtige Vergleich ist die eigene Historie: Nehmen Sie die letzten 90 Tage als Ausgangslinie und vergleichen Sie jede Woche damit.

## Zeitkennzahlen: Median statt Durchschnitt

Bei Zeiten führt der Durchschnitt in die Irre. Ein paar nachts eingegangene und morgens beantwortete Anfragen ziehen ihn um Stunden nach oben und verdecken das echte Tempo tagsüber. Deshalb wird für Zeiten der Median verwendet: der Wert, unter dem die Hälfte der Anfragen liegt.

| Zeitkennzahl | Messung | Hinweis |
|---|---|---|
| Erste Reaktionszeit | Von der Nachricht bis zur ersten Antwort durch Mensch oder Assistent | Innerhalb und außerhalb der Sprechzeiten getrennt |
| Zeit bis zum Termin | Vom ersten Kontakt bis zum Termin | Ist sie lang, kann der Kalender der Engpass sein |
| Entscheidungsdauer | Von der Planvorstellung bis zur Entscheidung | Zeigt die Qualität des Nachfassens |

Warum Tempo zählt und wie es gemessen wird, steht ausführlich unter [Reaktionszeit bei Patientenanfragen](/blog/reaktionszeit-patientenanfragen).

## Vorlage für die Wochenkarte

Die Wochenkarte passt auf eine Seite und wird jeden Montag ausgefüllt. Neben jeder Zahl stehen die Spalten „Vorwoche“ und „90-Tage-Ausgangslinie“.

| Zeile | Diese Woche | Vorwoche | 90-Tage-Ausgangslinie |
|---|---|---|---|
| Eingegangene Anfragen | | | |
| Median erste Reaktion (Sprechzeiten) | | | |
| Median erste Reaktion (außerhalb) | | | |
| Erreichungsquote | | | |
| Terminquote | | | |
| Erscheinensquote | | | |
| Planannahmequote | | | |
| Beginnquote | | | |
| Häufigstes Einwand-Schlagwort | | | |
| Die eine Verbesserung dieser Woche | | | |

Die letzte Zeile ist die wichtigste. Das Team ändert jede Woche nur eine Sache, etwa die Uhrzeit der Terminerinnerung oder die Antwort auf die Preisfrage, und prüft in der Folgewoche die Wirkung. Wer fünf Dinge gleichzeitig ändert, weiß nicht, was gewirkt hat.

## Die goldene Regel des CRM

Ohne ein CRM mit sauber gepflegten Daten lässt sich die Wochenkarte nicht füllen. Die goldene Regel ist einfach: Was nicht im CRM steht, ist nicht passiert. Jede Anfrage wird ein Eintrag, jeder Kontakt wird festgehalten, jeder Stufenwechsel am selben Tag aktualisiert und jeder Abschluss mit Grund versehen. Das klingt nach Disziplin, ist aber eine Frage der Gestaltung: Je mühsamer die Eingabe, desto mehr Lücken. Ein Aufbau, bei dem Gespräche automatisch im CRM landen, liefert immer verlässlichere Daten als einer, bei dem eine Koordinatorin alles abtippt. Wie ein Praxis-CRM aufgebaut wird, steht auf der Seite [Praxis-CRM](/de/praxis-crm).

## Gesprächsbogen

Zahlen zeigen, was sich verändert hat; Gespräche zeigen, warum. Jede Woche werden einige zufällig gewählte Gesprächsaufzeichnungen oder Nachrichtenverläufe mit dem folgenden Bogen bewertet. Jeder Punkt bekommt 0 (fehlt), 1 (teilweise) oder 2 (vollständig), insgesamt also 20 Punkte.

| Nr. | Kriterium | 0–2 |
|---|---|---|
| 1 | Begrüßung und Vorstellung | |
| 2 | Nach Ziel und Sorge der Person fragen | |
| 3 | Zuhören, nicht unterbrechen | |
| 4 | Die Worte der Person zusammenfassend zurückgeben | |
| 5 | Medizinische Fragen an die Ärztin weitergeben | |
| 6 | Kosten zusammen mit dem Umfang erklären | |
| 7 | Bei Einwänden nach dem eigentlichen Grund fragen | |
| 8 | Keine Versprechen, keine Drucksprache | |
| 9 | Einen klaren nächsten Schritt vorschlagen | |
| 10 | Das Gespräch korrekt im CRM erfassen | |

Der Bogen ist ein Coaching-Werkzeug, kein Benotungsinstrument. Er wird gemeinsam mit der Koordinatorin durchgegangen, und der Punkt mit der niedrigsten Bewertung wird Schwerpunkt der Woche. Gesprächsaufzeichnungen sind nur mit Information und in der Regel Einwilligung der Beteiligten zulässig; die Informationspflichten nach [Art. 13 DSGVO](https://dsgvo-gesetz.de/art-13-dsgvo/) gelten, und das unbefugte Aufzeichnen des nichtöffentlich gesprochenen Wortes ist nach § 201 StGB strafbar. Klären Sie das Vorgehen mit Ihrer Datenschutzberatung.

## Häufige Fehler beim Messen

- **Ziele nach Branchenwerten setzen.** Ein „Branchendurchschnitt“ unklarer Herkunft sagt nichts über Ihre Praxis.
- **Zeit mit dem Durchschnitt messen.** Ein paar Ausreißer verzerren das Bild.
- **Kanäle zusammenwerfen.** Telefon-, WhatsApp-, Instagram- und Formularanfragen verhalten sich unterschiedlich; getrennt erfassen.
- **Abschlussgründe nicht festhalten.** „Verloren“ allein lehrt nichts.
- **Die Wochenkarte als Strafinstrument nutzen.** Hat das Team Angst vor den Zahlen, sinkt die Datenpflege.

## So läuft die Wochenrunde

Für die Wochenkarte braucht es keine lange Besprechung; zwanzig Minuten reichen. Ein Vorschlag: zuerst das Ergebnis der Verbesserung aus der Vorwoche, dann der Vergleich der fünf Quoten mit der 90-Tage-Ausgangslinie, dann gemeinsam ein oder zwei Gespräche zur am stärksten gesunkenen Quote anhören und zum Schluss die eine Verbesserung dieser Woche festlegen und einer Person zuordnen. Besprochen wird der Prozess, nicht einzelne Personen. Nimmt einmal im Monat eine Ärztin teil, versteht das Team die medizinische Seite von Veränderungen bei der Planannahme besser.

## Messung, die von selbst läuft

Im [Praxis-CRM](/de/praxis-crm) von STOAIX wird jedes Gespräch, ob über WhatsApp, Instagram, Telefon oder Webformular, automatisch einem Anfrage-Eintrag zugeordnet. Stufenwechsel, erste Reaktionszeiten und Einwand-Schlagworte werden erfasst, sodass die Quoten der Wochenkarte ohne Handrechnung sichtbar sind. Die Deutung der Zahlen, die Wahl der Verbesserung und das Coaching bleiben Aufgabe des Teams.

## Häufige Fragen

### Wie hoch sollte die Umwandlungsquote einer Praxis sein?

Eine für alle gültige Quote gibt es nicht; Behandlungsart, Kanal und Preisniveau verändern das Ergebnis stark. Das sinnvollste Ziel ist, die eigenen letzten 90 Tage als Ausgangslinie zu nehmen und sich Woche für Woche zu verbessern.

### Mit welcher Kennzahl sollte ich anfangen?

Wenn Sie heute nichts messen, beginnen Sie mit dem Median der ersten Reaktionszeit und der Terminquote. Beide lassen sich am schnellsten verbessern und zeigen am schnellsten Wirkung.

### Dürfen Gesprächsaufzeichnungen ausgewertet werden?

Aufzeichnen und Auswerten ist Verarbeitung personenbezogener Daten; Patientinnen und Mitarbeitende müssen vorab informiert werden und in der Regel einwilligen, und Aufzeichnungen müssen sicher und nur zweckgebunden gespeichert werden. Richten Sie das mit Ihrer Datenschutzberatung ein.

### Wer füllt die Wochenkarte aus?

Die Koordinatorin oder Praxismanagerin, die für den Prozess verantwortlich ist, füllt sie aus, und das Team liest sie gemeinsam in der Wochenrunde. Kommen die Daten aus dem CRM, sinkt der Aufwand deutlich.
