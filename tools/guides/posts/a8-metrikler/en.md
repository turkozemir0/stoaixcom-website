> **Short answer:** Five rates are enough to measure the enquiry process: contact, booking, attendance, treatment plan acceptance and treatment start. Add the median first response time. Compare each rate with your own last 90 days, not with industry averages. Put the numbers on a one-page weekly scorecard, and each week review a few randomly chosen calls with a 10-point form, so you can see why a number moved, not just that it did.

## What is a patient enquiry conversion metric?

A patient enquiry conversion metric shows what share of enquiries move from one stage to the next, from first contact to starting treatment. Most clinics look at just two numbers: how many enquiries came in from ads or social media, and how many patients were treated at month end. Everything between them stays in the dark. When a month goes badly, nobody knows whether the problem is the advertising, the phone, the treatment plan or the follow-up, so the most visible lever, the ad budget, is usually the one that gets pulled. Stage-by-stage measurement shows exactly where enquiries are lost. This part gives you a scorecard a coordinator can complete in half an hour a week, and a call review form the team can use to measure conversation quality. The aim is not to produce reports; it is to fix one thing every week.

## Five core rates

| Rate | Formula | What it shows |
|---|---|---|
| 1. Contact rate | Enquiries with a conversation started / enquiries received | Speed and channel of first response |
| 2. Booking rate | Enquiries booked / enquiries with a conversation | Quality of the first conversation |
| 3. Attendance rate | Patients who attended / patients booked | Reminders and trust |
| 4. Plan acceptance rate | Plans accepted / plans presented | Plan, fees and follow-up |
| 5. Start rate | Treatment started / plans accepted | Deposits, scheduling, last worries |

Multiplying the five rates gives total conversion from enquiry to treatment start. When total conversion falls, checking which rate fell tells you where to begin.

We do not give a general "good" value for these rates. Comparing clinics with different treatments, channels, locations and fee levels using a single number is misleading. The right comparison is with your own history: take your last 90 days as a baseline and check against it every week.

## Time metrics: median, not mean

When measuring time, the mean misleads. A few enquiries arriving at night and answered in the morning drag the mean up by hours and hide your real daytime speed. So use the median for time metrics: the value half of your enquiries fall below.

| Time metric | Measurement | Note |
|---|---|---|
| First response time | From the patient's message to the first human or assistant reply | Track in-hours and out-of-hours separately |
| Time to appointment | From first contact to appointment date | If long, the diary may be the bottleneck |
| Time to decision | From plan presentation to decision | Shows follow-up quality |

Why speed matters and how to measure it is covered in detail in [speed to lead for clinics](/blog/speed-to-lead-clinics).

## Weekly scorecard template

The scorecard is one page and is completed every Monday. Next to each figure sit "last week" and "90-day baseline" columns.

| Row | This week | Last week | 90-day baseline |
|---|---|---|---|
| Enquiries received | | | |
| Median first response (in hours) | | | |
| Median first response (out of hours) | | | |
| Contact rate | | | |
| Booking rate | | | |
| Attendance rate | | | |
| Plan acceptance rate | | | |
| Start rate | | | |
| Most frequent objection tag | | | |
| This week's one fix | | | |

The last row matters most. The team changes just one thing each week, such as the timing of the reminder message or the answer to the price question, and checks its effect the following week. Change five things at once and you cannot tell which worked.

## The CRM golden rule

The scorecard cannot be filled in without a CRM where data is entered properly. The golden rule is simple: if it is not in the CRM, it did not happen. Every enquiry becomes a record, every contact is logged, every stage change is updated the same day and every closure has a reason. This looks like a discipline issue but is really a design issue: the more effort data entry takes, the more gaps there are. A setup where conversations land in the CRM automatically always produces more reliable data than one where a coordinator types everything in. How to set up a clinic CRM is on the [clinic CRM](/en/clinic-crm) page.

## Call review form

Numbers show what changed; conversations show why. Each week, a few randomly selected call recordings or message threads are reviewed with the form below. Each item scores 0 (absent), 1 (partly) or 2 (fully), for a total of 20.

| No. | Criterion | 0–2 |
|---|---|---|
| 1 | Greeting and introduction | |
| 2 | Asking about the patient's goal and concern | |
| 3 | Listening without interrupting | |
| 4 | Summarising the patient's words back to them | |
| 5 | Passing clinical questions to the clinician | |
| 6 | Explaining fees together with scope | |
| 7 | Asking for the real cause behind an objection | |
| 8 | No promises or pressure language | |
| 9 | Proposing a clear next step | |
| 10 | Logging the conversation correctly in the CRM | |

The form is a coaching tool, not a grading tool. It is reviewed together with the coordinator, and the lowest-scoring item becomes that week's focus. Patients and staff must be told that calls are recorded and reviewed; under [UK GDPR](https://ico.org.uk/for-organisations/uk-gdpr-guidance-and-resources/individual-rights/the-right-to-be-informed/), the right to be informed applies.

## Common measurement mistakes

- **Setting targets from industry averages.** An "industry average" of unclear origin says nothing about your clinic.
- **Measuring time with the mean.** A few outliers distort the picture.
- **Merging channels.** Phone, WhatsApp, Instagram and form enquiries behave differently; track them separately.
- **Not recording why enquiries closed.** "Lost" on its own teaches nothing.
- **Turning the scorecard into a punishment.** If the team fears the numbers, data entry drops.

## How the weekly meeting runs

Reading the scorecard does not need a long meeting; twenty minutes is enough. A suggested flow: first discuss the result of last week's one fix, then compare the five rates with the 90-day baseline, then listen together to one or two conversations linked to the rate that fell most, and finally pick this week's one fix and assign it to one person. Talk about the process, not individuals. Having a clinician join once a month helps the team understand the clinical side of changes in plan acceptance.

## Frequently asked questions

### What should a clinic's enquiry conversion rate be?

There is no single rate that applies to everyone; treatment type, channel and fee level change results enormously. The most useful target is to take your own last 90 days as a baseline and improve on it week by week.

### Which metric should I start with?

If you measure nothing today, start with median first response time and booking rate. These two are the quickest to improve and show results fastest.

### Is it legal to review call recordings?

Recording and reviewing calls is processing personal data; patients and staff must be informed in advance, and recordings must be kept securely and only for their purpose. We recommend setting this up with your data protection adviser.

### Who should fill in the scorecard?

The coordinator or practice manager responsible for the process fills it in, and the team reads it together in the weekly meeting. Pulling the data from the CRM greatly reduces the effort.
